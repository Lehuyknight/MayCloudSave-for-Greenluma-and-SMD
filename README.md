# May Cloud Save

Launcher Windows để đồng bộ save / mod Steam giữa các máy.

Tải bản mới nhất: [Releases](https://github.com/Lehuyknight/MayCloudSave/releases/latest)

1. Tải `MayCloudSave-portable.zip`
2. Giải nén rồi chạy `MayCloudSave-portable.exe` (không cần cài đặt)
3. Đăng nhập → Quét Steam → Đồng bộ

Config + log trên máy: `%USERPROFILE%\.may-agent\`
